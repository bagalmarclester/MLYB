# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this repository or associated deployments, please report it responsibly.

### How to Report
Please send an email to **[bagalmarclester@gmail.com](mailto:bagalmarclester@gmail.com)** with:
- A description of the issue.
- Steps to reproduce or a minimal proof of concept (without executing intrusive attacks).
- Any relevant logs, screenshots, or code references.

### Response Time
Reports are reviewed promptly, typically within 48 hours. Please do not open public GitHub issues for security vulnerabilities until they have been reviewed and addressed.
